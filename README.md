# Provenly (V1)

Provenly is a developer-first hiring platform that focuses on evaluating engineers based on real work, not resumes, buzzwords, or interview performance.

V1 is a foundational release built to validate one core question:
Can developer skill be reliably assessed using real GitHub projects and engineering signals?

---

## Status

🚧 V1 – Active Development

This version is intentionally minimal and experimental. Provenly V1 is not a full hiring marketplace yet.

---

## What V1 Does

### Developer Onboarding
- GitHub-only authentication
- Public repository linking
- Basic developer profile setup

### Project Evaluation
- Repository structure analysis
- Commit history and consistency signals
- Code ownership and activity patterns
- Project complexity indicators

### Feedback
- High-level evaluation insights
- Actionable feedback for improvement
- No rankings, no public scores

---

## What V1 Does Not Do (Yet)

- Client hiring or matching
- Payments or monetization
- Job postings
- Automated hiring decisions
- Full AI-driven scoring
- Interviews or messaging

These features are intentionally deferred until the core evaluation model is validated.

---

## Why Provenly Exists

Traditional hiring methods are increasingly unreliable:
- Resumes are inflated
- Interviews reward presentation over ability
- AI-generated portfolios blur real skill signals

Provenly is built around proof-of-work:
If you can build it, maintain it, and evolve it, that should matter more than how you sell yourself.

---

## Tech Direction (V1)

- GitHub as the source of truth
- Backend-first evaluation logic
- Minimal UI focused on clarity
- Infrastructure designed to scale after validation

---

## Roadmap (High-Level)

- V1: Developer onboarding + GitHub-based evaluation
- V2: Structured signals + deeper insights
- V3: Client access + controlled matching
- Future: Intelligent hiring workflows built on verified engineering data
